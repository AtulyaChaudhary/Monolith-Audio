# Getting started

> Create an application, copy the snippet, run it. Your first real response in about a minute.

You need an application to get a key. Creating one takes a few seconds and gives
you a **secret key** — the one you use from a server you control.

## 1. Create an application [#1-create-an-application]

Go to [the dashboard](/dashboard/applications) and create an application. You
will be shown a secret key exactly once. Store it somewhere your code can read
it, like an environment variable:

```bash
export SPICY_LYRICS_SECRET_KEY="sl_sk_..."
```

Never commit it, and never put it in code that runs in a browser.

## 2. Make a request [#2-make-a-request]

```bash
curl https://api.spicylyrics.org/v1/lyrics/TRACK_ID \
  -H "Authorization: Bearer $SPICY_LYRICS_SECRET_KEY"
```

```python
import os, requests

response = requests.get(
    "https://api.spicylyrics.org/v1/lyrics/TRACK_ID",
    headers={"Authorization": f"Bearer {os.environ['SPICY_LYRICS_SECRET_KEY']}"},
)
lyrics = response.json()
```

```javascript
// Node, or anywhere else you control the environment.
const response = await fetch("https://api.spicylyrics.org/v1/lyrics/TRACK_ID", {
  headers: {
    Authorization: `Bearer ${process.env.SPICY_LYRICS_SECRET_KEY}`,
  },
})
const lyrics = await response.json()
```

`TRACK_ID` can be a Spotify track id, an ISRC or an Apple Music track id. If you
only have a title, [search for it](/docs/finding-tracks).
